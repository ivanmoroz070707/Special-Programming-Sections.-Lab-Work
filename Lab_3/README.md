# OpenCV Camera Project


## Опис
Модульна C++ програма з OpenCV, яка читає відео з камери, відображає його, реагує на клавіатуру та миш, має кілька режимів обробки кадру.


## Вимоги
- Ubuntu / Debian-подібна система (тестовано на Ubuntu)
- libopencv-dev
- cmake, make, g++



## Інструкція
1. Клонувати репозиторій
2. Запустити (з прикладу):
```bash
./preinstall.sh
./build.sh
./run.sh
```
| Клавіша | Режим              | Опис                                                                                                                            |
| ------- | ------------------ | ------------------------------------------------------------------------------------------------------------------------------- |
| **1**   | Оригінал           | Відображення відео без будь-якої обробки                                                                                        |
| **2**   | Інверсія кольорів  | Створює ефект «негативу», інвертуючи всі кольори                                                                                |
| **3**   | Gaussian Blur      | Розмивання зображення методом Гауса                                                                                             |
| **4**   | Canny              | Виділення контурів на кадрі                                                                                                     |
| **5**   | Sobel              | Обчислення градієнтів та побудова карти контрасту                                                                               |
| **6**   | Бінаризація        | Перетворення зображення у чорно-білий режим за порогом                                                                          |
| **7**   | Glitch             | Ефект глітчу (зміщення каналів R/G/B для «зламаного» вигляду)                                                                   |
| **8**   | Picture-in-picture | Режим «картинка в картинці», у якому поверх кадру відображається зменшене додаткове зображення 				 |
| **q**   |		       | Вихід із програми                                                                                                               |
